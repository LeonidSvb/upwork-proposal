GDPR Setup for Events
How the CRM is configured to stay compliant with EU data protection rules for in-person and virtual events.

🔓

Double Opt-In on Registration

Every contact registers via the landing page and receives an automated confirmation email. Only after clicking confirm are they tagged GDPR OK and entered into event sequences.

✓ Configured
📄

Explicit Consent Fields in CRM

Each contact record stores: consent date, consent source (form URL), consent type (event-specific or community). This provides an audit trail if ever required by authorities.

✓ Configured
⚠

Data Retention Policy

Contacts who never confirmed GDPR are auto-deleted after 30 days. Community members who disengage are flagged for review at 12 months. Retention rules are enforced via CRM automation.

✎ Needs your input on retention period
🚫

Right to Erasure (Right to Be Forgotten)

One-click unsubscribe on every email. Unsubscribe triggers an automatic CRM workflow: contact is tagged Opted Out, removed from all sequences, and data is anonymised within 72 hours.

✓ Configured
🌎

Third-Party Processor Compliance

Any tool used (email platform, Zoom, analytics) is documented as a data processor. CRM stores which tools have access to which contact data to maintain a full data processing register.
